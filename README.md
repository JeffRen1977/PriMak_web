# PriMarkA Website

Marketing website for **PriMarkA** — a unified private markets platform connecting investors, asset managers, asset owners, and asset servicers.

## Pages

| Route | Content |
|-------|---------|
| `/` | Alternative investments (home / lending) |
| `/institutions` | Institutional investors, asset owners, managers, servicers |
| `/platform` | Platform capabilities |
| `/about` | Mission, vision, culture |
| `/contact` | Inquiry form |

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

Static output is in `dist/` — deploy to any static host (Vercel, Netlify, GitHub Pages, etc.).
